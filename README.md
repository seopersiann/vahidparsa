# وب‌سایت شخصی وحید پارسا

سایت فارسی، راست‌به‌چپ و استاتیک؛ بدون وابستگی اجرایی یا فرایند ساخت.

## اجرا و انتشار

برای پیش‌نمایش: `python3 -m http.server 8000` و سپس باز کردن `http://localhost:8000`.

برای GitHub Pages، در Settings → Pages گزینه Deploy from a branch، شاخه main و پوشه / (root) را انتخاب کنید. فایل CNAME دامنه vahidparsa.com را مشخص می‌کند. تنظیمات DNS در این پروژه تغییر نکرده است. فعال‌سازی دامنه و HTTPS به تنظیمات GitHub و DNS موجود بستگی دارد.

## ویرایش

- ساختار و پیوندهای رسمی شبکه‌های اجتماعی: index.html
- رنگ‌ها، چیدمان و اندازه‌ها: assets/css/style.css
- منوی موبایل، فیلتر و نمایش راهنماها: assets/js/main.js
- متن راهنماها: assets/js/lessons.json
- فونت وزیرمتن با مجوز OFL در assets/fonts؛ عکس واقعی ارائه‌شده در assets/images.

راهنماهای آموزشی داخل سایت باز می‌شوند و آدرس یا تاریخ انتشار ساختگی ندارند. اعداد معرفی همان مقادیر تقریبی ارائه‌شده هستند. صفحه تنها URL قابل ایندکس در نقشه سایت است. فایل 404 مخصوص دامنه اصلی تنظیم شده است.
